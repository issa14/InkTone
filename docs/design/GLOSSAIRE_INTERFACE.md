# Glossaire des textes d'interface

Un objet, un mot. Tout texte visible (libellé, titre, description TalkBack,
message) emploie le terme retenu ci-dessous. Origine : audit UI du
2026-11-16, §5.1.

| Objet | Terme retenu | À ne pas employer |
|---|---|---|
| Repère posé sur une page | **Signet** (« Ajouter un signet », « Retirer le signet », « Signets et notes ») | marque-page, page marquée |
| Activité de lecture à voix haute | **Narration** (« Écouter », « Narration en pause ») | TTS, contrôle vocal, haut-parleur |
| Réglage de la voix | **Voix** : « Voix naturelle », « Voix du téléphone », « Voix en ligne » ; la ligne s'appelle « Type de voix » | moteur, synthèse, neuronale, Sherpa-ONNX, UPMC, Edge |
| Temps passé, en statistiques | **Lecture** / **Écoute** | visuel, TTS |
| Écran de configuration | **Réglages** | paramètres |
| Écran des statistiques | **Statistiques** | statistiques de lecture |
| Recherche plein texte | **Rechercher dans les livres** / **Rechercher dans ce livre** | rechercher dans le texte des livres, dans vos livres |
| Mot-clé d'un livre | **Étiquette** | tag |
| Filtres d'état | **Non lus**, **En cours**, **Terminés** (pluriel : ce sont des ensembles) | non lu, terminé |
| Ouvrage importé | **Livre** | publication, ouvrage |
| Prononciation personnalisée | **Règles de prononciation** | dictionnaire phonétique |
| Thème de l'app (clair/sombre) | **Thème de l'interface** | thème (seul : désigne le thème de lecture) |
| Rapport d'erreur envoyé | **Rapport de plantage** | rapport de crash |

## Verbes de confirmation

| Verbe | Quand |
|---|---|
| **Enregistrer** | Crée ou modifie une donnée ou un réglage (règle, thème personnalisé, objectif) |
| **Appliquer** | Applique un réglage visuel sans quitter l'écran |
| **Démarrer** | Lance une action dans le temps (minuteur) |
| **OK** | Prendre acte d'un message, sans autre effet |

« Sauvegarder » est réservé à la sauvegarde des données (export chiffré).

## Forme

- Capitale initiale seule dans les titres ; « et » plutôt que « & ».
- Espace fine insécable avant `%`, `:`, `?`, `!` et les unités (« 42 % », « 10 s »).
- Points de suspension en un seul caractère : « … ».
- Pluriels écrits en entier, jamais « élément(s) ».
- Jamais de nom de bibliothèque, de modèle, d'unité de développeur (`sp`, `dp`) ni de norme (`WCAG`) dans un texte visible. Le diagnostic copiable d'« À propos » est l'exception : il sert au support.
